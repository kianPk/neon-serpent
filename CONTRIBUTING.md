# Contributing

Thanks for improving Neon Serpent.

## Playable file

Edit `PLAY.html`, then sync Pages:

```bash
cp PLAY.html docs/index.html
```

## Guidelines

- Keep the game self-contained (no build step)
- Preserve keyboard, swipe, and on-screen pad controls
- Update `CHANGELOG.md` for user-visible changes

## Local check

Open `PLAY.html` or serve `docs/` statically.
