# Neon Serpent

Arcade snake with rising speed, orb scoring, touch + keyboard controls, and local best score.

[![Demo](https://img.shields.io/badge/demo-live-0f1a22?style=for-the-badge)](https://kianpk.github.io/neon-serpent/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](./LICENSE)

## Play

**https://kianpk.github.io/neon-serpent/**

## Controls

- Desktop: Arrow keys / WASD
- Mobile: swipe or on-screen pad

## Stack

Vanilla JS · HTML5 Canvas/SVG · CSS · GitHub Pages

No frameworks. Runs offline once loaded.

## Local

```bash
python3 -m http.server 8080 --directory docs
# open http://localhost:8080
```
